What the system does with one thing the caller says

1  Listen speech → text → 2  Look it up knowledge base → 3  Write the reply language model → 4  Apply the rules eligibility, outcome → 5  Check it safety guards → 6  Speak

The key decision: the language model writes the words; the code owns the decisions. Eligibility, escalation and compliance wording are fixed in code, so neither the caller nor the model can talk the system out of them.

The four parts

Q1 · Voice agent

US health insurance. Qualifies a lead, handles objections, escalates to a human, writes to the CRM.

Q2 · Knowledge base

Messy web pages, PDFs and forms cleaned into cited records. Personal data removed, source errors quarantined.

Q3 · Local markets

Philippines in Taglish, Indonesia in Bahasa. Different sectors, flows and compliance rules — not a translation.

Q4 · Live nudges
