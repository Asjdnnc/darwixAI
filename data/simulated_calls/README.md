# Simulated calls — NOT the assessment's recorded-call evidence

Generated by `python scripts/simulate_call.py`. The caller's lines are **synthesized** with the same
local MMS voice the agent speaks with; only the transcription, agent and replies are real. These are
a reproducible end-to-end harness, not recordings of a human caller. The recorded calls that count
as evidence live in `Evidence/`.

## Why they are not used as evidence

Whisper handles MMS-synthesized speech noticeably worse than it handles a human, because MMS is a
monolingual model and pronounces English loanwords with local phonology. Across these four calls
**13 of 14 caller turns were altered by ASR**, and only one reached a real outcome:

| Spoken | Transcribed |
|---|---|
| Opo, sige po. | Poh, siguen Poh. |
| Pwede po ba sa GCash? | Pwede po ba sag-asi? |
| Iya, boleh. | Ia bule. |
| Nggih Mbak, dendanya kok mahal ya? | Nimbab dendanya kok mahal ya? |
| Besok. | Menurut. |

A human recording of the same script does better: in a real recorded Philippine call the same lines
came back as "cash" and "quincenas" — wrong, but close enough that the system recovers them.

## What they are useful for

- Re-running the whole pipeline (TTS -> real Whisper -> agent -> TTS) deterministically after a change.
- Evidence for the claim in `docs/Q3_MARKETS.md` section 3 that the Philippine ASR figures are an
  **upper bound on error**: they are measured on synthesized speech, which is harder than real speech.
